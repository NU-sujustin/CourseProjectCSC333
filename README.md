Project Objectives:
  Password Analyzer is a program designed to evaluate the strength of the user's password. 
  It helps users create mroe secure passwords by analyzing the characters they include and providing feedback
  The main goal is to:
    Check password security requirements
    Provide a clear strength rating
    Give userful hints to improve weak passwords

Features:
  Check for lowercase, uppercase, numbers, special, whitespaces, and character count
  Warns user if they include spaces in password
  Gives rating of 1-5
  Feedback and suggestions
  Analyze multiple passwords in a session

Requirements to run:
  Python 3.7 or higher
  Works in IDE(I used pycharm)
